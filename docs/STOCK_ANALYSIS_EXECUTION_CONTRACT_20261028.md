# 銘柄分析の標準実行契約（2026-10-28）

## 入力と確認
ユーザーが銘柄名または証券コードを入力したら、**分析前に適用フィルターを必ず確認**する。選択されるまで採点しない。メインフィルター2.3.1、金融フィルター1.1.1、売却判断フィルター1.0.1など、選択された正本を使用し、別フィルターへ無断変更しない。

## データ取得の順序
1. **EDINET DS** を第一の財務データソースとする。
2. EDINET DSで取得できない指標のみ、ユーザー指定の補完先（Yahoo!ファイナンス、IR BANK等）を参照する。
3. **EDINET原本は分析・採点・数値検証に使用しない。** 既存の原本取得システムや保存データは削除・変更せず維持するが、分析パイプラインからは分離する。
4. 取得できない項目は選択フィルターの欠損・非該当ルールで処理する。数値を推測・創作しない。

## 出典の必須表示
**採用する各数値に**、指標名、値、単位、会計期間または基準日、取得元サービス名、可能な場合は取得先URL、取得日時を付ける。補完先からの値にはその旨を表示する。出典が確認できない数値は「出典未確認」と明示して正式採点には使わない。計算指標は計算式と使用した入力値の出典を残す。

## 実行と安全性
既存のClaude設定、EDINET収集処理、main、index.csvを保護する。公開・成績記録への追加は、選択フィルターの正式判定が成立した場合だけに行う。実際に取得・実行していない処理を完了済みと報告しない。

この文書は新しいユーザー指示を明示するもので、EDINET DSの接続が実装済みであることを意味しない。
