# 日本株メインフィルター分析結果

このリポジトリは、メインフィルターによる日本株分析結果を保存・管理するためのリポジトリです。

## 運用ルール

- 現行基準：メインフィルター2.3.1
- 分析結果は銘柄コードごとに管理
- 分析日・基準日・スコア・判定・主要コメントを記録
- 後から再評価できるよう、分析時点の結果を残す
- 数値が確認できない場合は推定せず「欠損」「未確認」等で記録する

## ディレクトリ構成

```
/
├── README.md
├── results/
│   └── （銘柄別の分析結果）
└── index.csv
```

## 注意

このリポジトリは分析結果の保存先です。
投資判断そのものは、最新の開示資料・市場データ等を確認したうえで行います。
